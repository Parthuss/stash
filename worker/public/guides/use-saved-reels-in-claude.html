How to use your saved Instagram reels in Claude

By Parth Akholkar, who makes Skwirl · 9 November 2026

You saved a reel about scroll animations, a Claude skill, a GitHub repo, an activity to try with a client. The week you finally need it, you've forgotten it exists. Skwirl turns each reel you share to it into a note, and Claude can use those notes while you work.

What it does

  • Claude Code: with the Skwirl plugin, every message you send is checked against your saves automatically. If one fits the task, Claude gets it. If nothing fits, you see nothing.
  • Claude app and ChatGPT: connect Skwirl and they can search your saves when you work. They don't check every time, so it helps to ask.

Here's what the plugin looks like, from a test on a throwaway account on 9 November 2026. Nobody mentioned Skwirl in the message:

Prompt: Help me add a scroll-driven parallax hero to a landing page. Short plan only.

End of Claude's plan: Your saved post "4 Web Animation Patterns" (Web Pros, link) lists parallax, scrub and pin + transform as scroll patterns. This plan does the parallax.

In the same test, an unrelated question about git brought up nothing.

Set it up in Claude Code

You need a Skwirl account (free, no password, no card) and Claude Code installed.

  1. Open Skwirl, tap Set up, then open Connect ChatGPT or Claude.
  2. Under Using Claude Code?, tap Copy install command. It makes your personal key and puts it inside the command, which looks like this: 
    claude plugin install skwirl --marketplace Parthuss/stash --config key=YOUR_KEY
  3. Paste it into Terminal and press Enter.

The key only works for this plugin and Skwirl's connector. It can't be used to sign in to your account. Tapping the button again makes a new key and the old one stops working.

Set it up in the Claude app or ChatGPT

Your connector address is in the same place: Set up, then Connect ChatGPT or Claude.

  1. Claude: on claude.ai go to Settings, then Connectors, then Add custom connector. Name it Skwirl, paste the address, then tap Connect and Allow. It then works in the Claude phone app too.
  2. ChatGPT: on ChatGPT on the web open Plugins, then +, then Add custom MCP server. Name it Skwirl, paste the address as the Server URL and select OAuth. Create and install the plugin, sign in to Skwirl and tap Allow. Your workspace must allow custom connections.

To make Claude more likely to check while you work, add this line to your personal preferences in Claude's settings:

Before starting a build, design, writing, research or planning task, search my Skwirl connector by concept for anything I saved on it.

In ChatGPT, or any time Claude doesn't check, just say "check Skwirl for this".

What it's good for

  • Building: the Claude skills, GitHub repos and design ideas you saved to try later.
  • Planning sessions: therapists and teachers can sort activity ideas into their own categories and pull them up when planning.
  • Making content: hooks and formats you saved, while you write.

What gets sent

With the Claude Code plugin, each message you send goes to Skwirl. Claude Code also includes details like the folder you're working in and a session ID. Skwirl ignores those.

  • Your message is compared with your saves by Cloudflare's AI, using its first 2,000 characters, and then dropped. It's never stored or logged.
  • Very short messages and slash commands aren't searched at all.
  • If saves fit, up to three go back to Claude: title, short summary and whether you've used it yet. Claude can then open the full note.
  • Skwirl keeps a count of how often a save was brought up, not what you asked.

To stop it, tap Turn off in the same Set up card. Other users can't see your saves unless you share a note. The full details, including who else processes your data, are in the privacy policy.
